GOOD TO KNOW

Questions?
We’ve got you.

Some quick answers before you bring Emerald into your server.

Ask us on Discord ↗
How do I add Emerald to my server?

Use the Add to Discord button, choose the server where you have permission to add bots, review the requested permissions and authorise Emerald.

Is Emerald free to use?

Emerald offers a core set of server tools, with an optional Premium tier for additional perks and advanced options. Ask the support team for the latest Premium details.

Where can I find all commands?

Use the command explorer on this page for a selection of commands. For the complete, current list available to your server, run /help in Discord.

Can I configure Emerald for my server?

Yes. Emerald includes setup and configuration commands for systems such as logging, AutoMod, tickets, welcome messages, reaction roles and leveling.

Where do I get help or report a problem?

Join the Emerald support server. You can ask questions, report bugs and share ideas with the community.
