SAFETY DOCUMENTATION

AutoMod that goes beyond spam.

Emerald's saved source contains separate message-based filters and event-driven protections. Configure carefully and test the rules before enabling strict actions.

Message protection

Anti Spam checks rapid and sustained message bursts, repeated content, excessive message length, attachment floods, link floods, emoji floods and repeated characters.

Anti SpamAnti LinksAnti AdsBad WordsAnti Caps

Link & phishing checks

Anti Phishing evaluates suspicious scam/login patterns, suspicious URL structures and other indicators. Anti Bad URL checks message and attachment URLs against server-configured blocked patterns.

Anti PhishingAnti Bad URLAnti Invites / Ads

Mentions & media

Anti Mentions reduces excessive pings. Additional filters cover external emotes, ghost pings and other message-based behaviour.

Anti PingsAnti External EmotesAnti Ghostping

Join & server event protection

Anti Mass Join, Anti Account Join, Anti Bot Join and Anti Nuke monitor join activity or sensitive server events such as rapid channel/role changes.

Anti Mass JoinAnti Account JoinAnti Bot JoinAnti Nuke

Control the response

Choose actions such as deletion, warning, timeout, mute, report, lockdown or other configured responses where supported. Use role/channel allowlists and exemptions for trusted areas.

Test and review

Use /automod test, /automod test-rule, /automod recent-actions and /automod status to inspect and test rules.

About bulk cleanup

For spam bursts, Emerald attempts a bulk delete of the matching message batch. If bulk deletion fails, the code falls back to individual message deletions. Each detected action then follows Emerald's moderation response and logging flow. Discord permissions, message age and API limits can affect what can be removed.

STAFF WORKFLOWS

Moderation, tickets and logs.

Keep staff actions organised and make server operations easier to review.

Moderation & warnings

Ban, kick, warn, temporary ban/mute, soft-ban, hack-ban, mass-ban and mass-kick. Add notes, inspect a case, review member history, list warnings and view moderation statistics.

Channels & voice

Lock or unlock channels, lockdown a server, clear messages, set slowmode or reset a channel. Voice tools can mute, unmute, move or disconnect members.

Logging & audit trail

Configure server event logging and inspect status. Event categories include message edits/deletions, member events, moderation activity and AutoMod actions where enabled.

Tickets

Create ticket panels, configure the ticket category and staff roles, check setup status, and close support tickets.

Welcome, leave & roles

Set up welcome and leave messages, test the messages, configure auto-roles/DM options where available, and build reaction-role panels for self-service role selection.

Server tools

Back up server configuration and inspect server or user information. Use tags to save reusable answers and track their usage.

FREQUENTLY ASKED QUESTIONS

Good questions.
Clear answers.

Need help with a setup or a feature? Start here, then contact the support server for anything specific to your configuration.

Ask in support ↗
Is Emerald free to use?

Emerald includes core server management features. Some exclusive tools are gated behind Emerald Premium. Ask the support team for current activation and pricing information.

How do I see all commands available in my server?

Run /help in Discord. This website's command directory is a reference to the saved source build and may not exactly match what has synced to every server.

What is the best way to configure Emerald?

Start with /setup wizard, review /setup status, then customise modules from /settings. Test moderation rules before using strict actions.

Can I customise AutoMod?

Yes. The AutoMod systems provide configuration, test, status, allowlist and exemption tools. The available settings depend on the module and permissions in your server.

How does the privacy command work?

/privacy opens a private privacy panel. Deletion requires a second confirmation and attempts to remove the user's Emerald-managed records, saved participation references and known bot-created copies that Emerald can access. It cannot delete Discord platform records, messages written by the user, copies made by other people/bots or hosting backups.

Does the website show whether Emerald is online?

The footer includes a status indicator. GitHub Pages is a static host and cannot inspect the bot process directly, so a public status feed or monitoring service must be connected. Until then the indicator honestly displays that monitoring is not connected.

Where can I report a bug or request a feature?

Join the Emerald support server and share the issue, what you expected, what happened and any relevant error message. Never share your bot token or other credentials.

Does deleting my data remove everything on Discord?

No. Emerald can process data stored in its own files and database and make best-effort attempts to remove certain bot-authored posts. It cannot delete Discord's own service records, user-authored messages, screenshots, other people's copies or backups controlled by a hosting provider.
